El porcentaje, o tanto por ciento, indica una cantidad como partes de 100. Se escribe con el símbolo %. Por ejemplo, 32 % significa treinta y dos de cada cien.

Un porcentaje se puede escribir como fracción o como decimal: 45 % es igual a 45/100, y 32 % es igual a 0,32.

Para calcular el porcentaje de un número, primer paso: escribe el porcentaje como decimal. Segundo paso: multiplícalo por el número. Ejemplo: el 32 % de 2000 es 0,32 × 2000 = 640. Otro ejemplo: el 50 % de 80 es 0,50 × 80 = 40.
