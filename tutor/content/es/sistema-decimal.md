El sistema decimal es la forma habitual de escribir números. Usa como base el número diez.

Tiene diez cifras: 0, 1, 2, 3, 4, 5, 6, 7, 8 y 9.

Es posicional: el valor de una cifra depende del lugar que ocupa. En 352, el 3 vale 300, el 5 vale 50 y el 2 vale 2. Se usa en casi todo el mundo.
