Una fracción muestra partes de un todo. El numerador, arriba, indica cuántas partes se toman. El denominador, abajo, indica en cuántas partes iguales se divide el todo.

Cómo sumar fracciones con el mismo denominador: se suman los numeradores y se deja el mismo denominador. Ejemplo: 2/7 + 3/7 = 5/7.

Cómo sumar fracciones con distinto denominador: primero se buscan fracciones equivalentes que tengan el mismo denominador, y luego se suman los numeradores. Ejemplo: 1/2 + 1/4. Como 1/2 es igual a 2/4, queda 2/4 + 1/4 = 3/4.

Al terminar una suma de fracciones, a veces se puede simplificar el resultado. Por ejemplo, 2/4 es lo mismo que 1/2.
